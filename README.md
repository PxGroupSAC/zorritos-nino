# Zorritos ante El Niño

Infografía y mapa interactivo de zonas de peligro por quebradas, lluvias y mar en el litoral de Zorritos (Contralmirante Villar, Tumbes), con cronología 1983–2026 y fuentes oficiales (INGEMMET, INDECI, CENEPRED, ANA, CAF, SENAMHI, ENFEN).

- Página: `index.html` (autocontenida, 4,5 MB)
- Mapa general en alta resolución: `zorritos-mapa-general.jpg`

Datos cartográficos: Sentinel-2 cloudless 2024 (EOX, CC BY-NC-SA 4.0), Terrain Tiles (Mapzen/AWS), OpenStreetMap (ODbL), Esri World Imagery en las fichas.
